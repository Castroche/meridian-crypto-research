## 当前运行证据

- 调度器包含 `monitor-market`、`monitor-context`、`reconcile-products`、`report-08:00`、`report-20:00`和 `daily-00:10`。
- 最新完整报告通过 `validate_report` 后入库，三资产均有四维证据与数据源。
- 自动化测试覆盖指标、报告协议、失效方向、模糊措辞拒绝、期权/基本面覆盖、调度、结算、存储和无配置分发。
- 浏览器快照确认实时数据、BTC 期权和算力证据可见；控制台 0 错误、0 警告。
- `/data/meridian.db` 与 `/backend/app/main.py` 均返回 404，静态服务没有暴露数据库或源码。

“准确”在产品中定义为证据可追溯、概率可校准、预测可结算，而不是承诺必然命中。滚动准确率只统计到期样本，不提前展示虚假胜率。
