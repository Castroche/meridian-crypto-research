# 研究编辑标准

## 产品分层

- Tactical Monitor 与 Daily Market Strategy 保留行情、判断、条件计划及复盘规则。
- 深度文章独立选题、取材、写作和审稿。覆盖 Web3、链上、AI 技术与圈层、全球资本流动性、股票公司与商业变化；每篇只回答一个具体问题。
- 定时任务表示发起研究与编辑的时间，不承诺无条件发布。材料不足、审稿未通过或模型故障时暂缓本篇，保留已发布文章，不生成模板保底稿，也不阻断其他产品。

## 深度文章的写法

以用户提供的技术解读与人物商业故事为编辑校准样本，吸收通用叙事方法，不复制作者的具体措辞或作品内容。

- 先确定值得追问的问题和具体切口，再决定章节。章节数、段落数与顺序没有固定合同。
- 技术解读从真实任务进入；说明读者遇到的问题后引入术语，再解释机制、比较条件、收益与代价。
- 人物和商业故事让行为、经历与商业细节推进；经历必须解释人物选择。材料充分后再展开行业意义，避免猎奇与虚构心理。
- 宏观和公司文章解释参与者约束、制度与资金路径；不默认映射 BTC/ETH/SOL，不强制投资建议。
- 每段应增加事实、解释机制、推进故事或限定判断。删除空泛背景、换词重复、例行总结与机械过渡。
- 重要限制紧贴对应论断；相关性、代理指标和厂商自述均不能冒充独立因果证据。
- 结尾回答开头的问题，可回到人物、任务或具体未解问题，不重复全文。
- 市场共识、Meridian 分歧、反方路径、投资含义都不是必填章节。新文章不呈现固定判断卡片。

## 篇幅

不设置硬性字数下限或上限。以正文可见字符数统计，标题、引用标记和空白不计入。

| 内容 | 建议篇幅 |
|---|---:|
| 聚焦事件 | 2000～3500 字 |
| 技术、人物、商业故事（默认参考） | 3500～6000 字 |
| 复杂专题 | 6000～10000 字，必要时更长 |

建议区间不参与发布判定。短稿检查是否挖掘不足，长稿检查是否重复。禁止为了字数增加套话或截断内容。模型单次输出与函数运行仍有资源预算；超时或截断视为未完成，不能伪装为完整文章。

## 材料与计算

- 取材与选题绑定。深度文章不自动混入实时三资产行情或主题无关图表。
- 从可读来源正文提取事实、人物行为、商业细节、比较条件和限制；每条提取事实需附能在原文匹配的短证据。内部资料包保留有界正文，供编辑核验；阅读页不再发布来源全文。
- 标题、转载数量、同域页面数不等于独立证据。一般需要独立来源交叉核对；一份完整一手文件可以支持明确归属于该文件的窄问题解读，不能凭此声称行业共识或独立领先。
- 事实段落应引用相应事实；纯过渡可以没有引用，但审稿必须确认其中没有新增事实。
- 直接数字必须由本段引用授权，禁止仅因为其他材料出现相同数字就自动补上引用。
- 允许透明演算：输入、单位、来源/假设、公式、结果与限制均需声明。程序仅计算已声明变量的加减乘除，拒绝任意代码和错误结果。
- 假设演算必须在正文标注为假设或示例，不得冒充实际观测。程序核算不能替代编辑对口径和单位的检查。

## 写作、审稿和发布

1. 根据资料形成主线计划，再连贯生成整篇；导语、正文、结尾不再互不知情地并行生成。
2. 编辑检查可以记录中心问题、证据、因果边界、叙事推进、信息密度及结尾，但不再阻断发布。
3. 只要模型返回结构完整的文章并通过基础 JSON、引用和数字安全校验，即可发布；编辑意见作为后续优化信息保存。
4. 程序仍拦截空正文、未知引用、未授权数字和无法复算的计算；这些属于生成失败，不是审稿意见导致的退稿。
5. 正文不再因为重复、推论幅度或编辑评分被挡住。下一轮生成可以参考这些问题，但不覆盖已经生成的文章。
6. 草稿键包含编辑版本和材料指纹；旧版分段不会被新流程复用。
7. 不再按字数、章节数或字段存在与否生成“80 分通过”的质量分。语义审稿仍是模型辅助，不能保证消除所有事实错误；重要稿件保留人工校准。

## Tactical / Daily 专用规则

以下条目不约束深度文章的叙事结构：

- 结论优先，区分事实、推断与条件预测；数据源、时点、窗口、单位和缺失项可见。
- Tactical 每个资产给出有边界的判断与完整条件计划；走势不明保留双向条件方案。
- 入场使用区间，止损与三级止盈几何合法；减仓比例合计 100%，单笔权益风险不超过 0.5%，杠杆不超过 2 倍。
- Daily 复盘北京完整自然日，给未来 24–72H 大盘情景，不输出 Preferred Trades；未校准前不用精确概率。
- 反方论据必须能挑战判断，不用泛化风险清单代替。缺失值显示 N/A，不以代理指标伪装完整性。
- 禁止收益保证。数据不足按产品规则降级、说明限制，保留定时发布与复盘。
