# 产品规格：Meridian Crypto Research

## 1. 产品目标

面向需要高频、可执行、可复盘观点的加密资产研究用户。每日固定发布 Daily Market Strategy、各 checkpoint 固定发布 Tactical Monitor、每日启动深度文章研究与编辑，通过质量门槛后发布。报告必须把事实、推断和预测分开，所有核心观点均可追溯、可证伪。

## 2. 固定报告时点

| 时点（UTC+8） | 研究重点 | 数据截点 |
|---|---|---|
| 00:10 | Daily：前一个北京自然日 00:00:00–23:59:59 复盘与 24–72H 情景 | 00:05 后最新可用数据 |
| 08:00 | Tactical：隔夜结构、亚洲开盘与三资产实时决策 | 生成前强制刷新 |
| 20:00 | Tactical：欧洲时段、美盘前段与三资产实时决策 | 生成前强制刷新 |

报告批次使用唯一 `as_of` 时间。晚到数据只能进入下一批，禁止悄悄改写已发布报告。重大事件可产出额外快讯，但不替代固定报告。

## 3. 四维研究框架

### 新闻面

- 监管、政策、诉讼、交易所与托管风险
- 项目升级、生态事件、安全事故
- 宏观数据、央行、美元与风险偏好
- 新闻必须记录来源、发布时间、首次发现时间、来源等级和交叉验证状态

### 技术面

- 多周期趋势：15m、1h、4h、1d、1w
- 市场结构：高低点、成交量分布、关键支撑阻力、波动率
- 动量与趋势指标只作证据，不单独形成交易结论
- 使用统一交易所聚合价格，避免单点异常

### 资金面

- 现货净流、稳定币供给与交易所余额
- ETF/基金申赎、CME 与机构基差
- 永续合约资金费率、未平仓量、清算、期权偏度和期限结构
- 链上大额转账需要实体标签和上下文，禁止把单笔转账直接解释成买卖

### 基本面

- BTC：安全预算、算力、矿工行为、长期持有者结构
- ETH：质押、燃烧与发行、L2 活跃度、费用与开发升级
- SOL：费用与收入、活跃地址、DEX 交易、稳定币、验证者与客户端进展
- 网络原始活跃指标需要去机器人和女巫噪声

## 4. 核心观点协议

Daily 与 Tactical 不共用资产 schema。Daily 使用自然日 OHLCV、最大回撤、链上积极度、情绪/爆仓、新闻传导与 High/Medium/Low 大盘情景，不输出独立交易建议。Tactical 使用最新数据、多周期趋势、关键位、衍生品定位与条件交易计划。

共用置信度拆分为：

- ViewConviction
- EvidenceQuality
- DataCoverage
- ModelConfidence（仅在完成历史校准后输出）
- TradeQuality（仅存在 edge 时输出）

历史 V4 资产协议如下，仅用于读取旧报告：

```json
{
  "asset": "BTC",
  "as_of": "2026-07-11T08:00:00+08:00",
  "horizon": "24h",
  "stance": "bullish | neutral | bearish",
  "conviction": 72,
  "target_range": [0, 0],
  "invalidation": {
    "price": 0,
    "condition": "4h close",
    "reason": "结构被破坏的原因"
  },
  "thesis": "不超过 80 字的明确判断",
  "evidence_ids": ["market:...", "news:..."],
  "risks": ["已知、具体、可监测的反向证据"]
}
```

### 语言规则

- 先写判断，再写证据。
- 禁止无依据的“看涨/看跌”和伪精确目标价。
- 少用“可能、若、或许、预计”等空泛措辞；用概率、时间窗、触发条件和失效条件表达不确定性。
- “事实”必须带数据时间与来源；“推断”必须列证据；“预测”必须有期限和评分方式。
- 不承诺确定收益，不把模型输出包装成事实。

## 5. 报告结构

### Tactical Monitor

1. 一句话大盘结论，用总市值、市场宽度、BTC 市占率、成交量、波动、资金费率和 OI 变化解释。
2. BTC / ETH / SOL 各自显示现价、24H、15M/1H/4H/1D、成交量、支撑压力、资金费率、OI、强弱、主导与反方证据。
3. 方向明确时输出一个主计划；方向不明时显示观望并同时输出上破多单与下破空单。每个计划都有触发、入场区、硬止损、三档止盈、40/30/30 减仓、风险收益比、取消条件和有效期。

### Daily Market Strategy

1. 前一个北京自然日的全天总结、总市值、成交量、BTC 市占率、市场宽度与阶段归因。
2. 恐慌贪婪指数与前日变化；24H 爆仓多空分布并显示覆盖口径。
3. BTC / ETH / SOL 的 OHLCV、涨跌、最大回撤、强弱、趋势、支撑压力、支持/反方证据与失效条件。
4. 链上积极度、费用、TVL、稳定币、资金流、活跃地址与指标覆盖率。
5. 地缘、FOMC、非农、CPI、监管、ETF 和行业事件的时间、来源、已观察反应与推断传导路径。
6. 未来 24–72H 基准、上涨、下跌情景与风险事件；不输出 Preferred Trades。

## 6. 准确性与复盘

每条预测在 1d、3d、7d 自动结算：

- 方向准确率：预测方向与实际收益方向是否一致。
- 区间命中率：价格是否进入目标区间。
- Brier Score：情景概率是否校准。
- 最大逆向波动：观点发布后的 MAE。
- 最大顺向波动：观点发布后的 MFE。
- 来源贡献：移除某类证据后表现变化。

仪表盘展示滚动 30/90 天结果，并按资产、时点、市场状态拆分。低样本量不展示胜率，只展示样本数和置信区间。

## 7. 发布门槛

- 行情超过 30 分钟仍发布，但数字计划标记 STALE、不得伪装为实时执行建议。
- 至少两个独立价格源一致，偏差不超过预设阈值。
- 高影响新闻至少一个一手来源，或两个可靠二手来源交叉验证。
- 所有数字可追溯到数据记录；所有核心结论至少绑定两条独立证据。
- 目标区间合法，失效条件可机器判定；精确概率必须具有可审计的校准记录。
- 数据不足时仍按时发布，明确显示 N/A、DataCoverage 与判断限制，不生成伪精确判断。
- Daily/Tactical 保留定时发布与修复降级。深度文章不设字数硬上下限，材料或编辑核验未通过时暂缓；Tactical 即使 NO_ACTION 也保留完整条件参考计划。
- 同一产品、北京时间日期和时点形成唯一发布键；默认接口只展示 CURRENT，SUPERSEDED 版本保留按 ID 审计。
